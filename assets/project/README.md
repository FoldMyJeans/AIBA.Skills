## How to read this folder

- `knowledgebase/01_Requirements_Source.md` holds why the work exists, the dials, the scope and the stakeholders. Start here.
- `knowledgebase/02_Conventions.md` holds what this project has declared, meaning IDs, closed vocabularies and windows.
- `knowledgebase/03_Backlog_and_Tracking.md` holds where the stories and tickets live, and how they move.
- `knowledgebase/04_Worklog.md` holds the decisions log and the history.
- `sources/` holds raw transcripts, notes and exported threads, which is the evidence everything else points back to.
- `prototype/` holds the clickable mock, when one exists.
- `[project]_User_Stories.xlsx` is the workbook, with one row per story.

On a Lean, tier 1 project, 02 and 03 are allowed to collapse into this README until the project earns them back. 01 and 04 always stay separate, because why and history are the two files a dispute actually needs.
